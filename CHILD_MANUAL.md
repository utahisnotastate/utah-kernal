# 🚀 Building Your Own Magic Computer!

Hi! Did you know that the computer you are using right now is actually wearing a heavy backpack?

Computers like Windows or Mac are very smart, but they are also very scared. They are scared that a bad program might accidentally break the screen or erase a file. So, they put all the programs inside a padded playground (called "User Space") and force them to ask permission for *everything*.

Asking for permission takes a lot of time. It makes the computer hot and tired.

### The Utah-Kernel Superpower

We built something called the **Utah-Kernel**. It takes off the heavy backpack.

Instead of putting programs in a padded playground, we use a special magic language called **WebAssembly**. WebAssembly is like a super-smart teacher. It looks at the program *before* it starts running and says, "I have checked the math, and this program is perfectly safe. It will not break anything."

Because the teacher already checked the math, the computer doesn't have to be scared anymore!

With the Utah-Kernel:

1. We let the programs sit right in the driver's seat of the computer.
2. They get to push all the buttons and steer the wheel without asking permission.
3. The computer runs faster than a race car, and uses almost no energy!

You are going to learn how to write a simple program, put it in the Utah-Kernel, and watch it drive the computer all by itself!
